# IBM Data Science Professional Certificate

Repository of my IBM Data Science Professional Certificate, done in the Coursera platform.


This specialization was divided into 12 courses, each one with several modules:

- **Course 1 of 12:** What is Data Science?
- **Course 2 of 12:** Tools for Data Science
- **Course 3 of 12:** Data Science Methodology
- **Course 4 of 12:** Python for Data Science, AI & Development
- **Course 5 of 12:** Python Project for Data Science
- **Course 6 of 12:** Databases and SQL for Data Science with Python
- **Course 7 of 12:** Data Analysis with Python
- **Course 8 of 12:** Data Visualization with Python
- **Course 9 of 12:** Machine Learning with Python
- **Course 10 of 12:** Applied Data Science Capstone
- **Course 11 of 12:** Generative AI: Elevate Your Data Science Career
- **Course 12 of 12:** Data Scientist Career Guide and Interview Preparation
